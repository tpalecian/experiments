# Catan — Three.js

Local hotseat Settlers of Catan built with Vite, TypeScript, and Three.js.

## Run

```bash
npm install
npm run dev
```

## Play

1. Choose 2–4 players
2. Place settlements and roads in snake-draft setup
3. Roll, collect resources, bank-trade, build roads/settlements/cities
4. On a 7, discard if needed, move the robber, steal
5. First to 10 victory points wins

## Notes

- Development cards are not in this MVP
- Longest Road (2 VP at length ≥ 5) is included
- Board layout uses the standard 19-hex island with harbors
